Instructions for running Code Snippet dc.py
---------------------------------------------
Prerequisites:
1. Python Installation: Ensure Python is installed on your system. You can download it from [here](https://www.python.org/downloads/).
2. Install Required Libraries: Install the following Python libraries before running the code. You can use `pip` to install them by executing the following commands in your terminal:
   Terminal
   pip install opencv-python
   pip install cvzone
   pip install numpy
   

 Steps to Run the Code:

1. Setup the Python Script:
   - Save the provided Python code to a `.py` file, for example, `hand_gesture_capture.py`.

2. Create the Data Directory:
   - Ensure you have a folder named `Data` in the same directory as the script or wherever you plan to store the collected hand gesture images. The images will be saved into subfolders labeled with gesture names (A-Z) depending on the user input.

3. Run the Script:
   - Open a terminal or command prompt in the directory where the script is located.
   - Run the script by typing:
     Terminal
     python hand_gesture_capture.py
4. Input Gesture:
   - The script will ask you to enter the gesture or letter you want to collect data for (for example, 'A', 'B', 'C', etc.). Enter the letter and press `Enter`.

5. Webcam Initialization:
   - The webcam will activate, and you'll see a live feed showing the hand and the processed image for gesture recognition.

6. Capture Images:
   - Once the hand is detected, press the `s` key to save the processed hand image.
   - The image will be saved in the specified folder, with the file name including a timestamp to avoid overwriting.

7. Quit the Program:
   - Press `q` at any time to quit the program, releasing the webcam and closing all OpenCV windows.

 Example Use Case:
- When collecting gesture data for the letter 'A', enter `A` when prompted.
- Every time you press `s`, a new image will be saved in the `Data/A/` folder.

Steps to run code model_training.py
Here are the steps to run the CNN model code for gesture recognition:

 1. Install Required Libraries
   Install the necessary libraries using `pip`:
   terminal
   pip install tensorflow scikit-learn seaborn matplotlib
   

 2. Prepare the Dataset
   - Ensure you have the dataset structured as described earlier (e.g., `Data/A`, `Data/B`, etc.).
   - Place it in the appropriate directory (`Data` by default) or update the `data_dir` path in the script.

 3. Create the `data_preprocessing.py` Script
   Ensure you have the `data_preprocessing.py` script created from the previous step, which contains the `load_and_preprocess_data` function to load and preprocess your dataset.

 4. Save the CNN Script
   Save the provided CNN model code in a Python file, for example, `cnn_model.py`.

 5. Run the CNN Script
   Open a terminal or command prompt in the directory where the CNN script is saved and run:

   terminal
   python cnn_model.py
   

 6. Model Training and Visualization
   - The script will load the dataset, train the CNN model for 10 epochs (you can modify `epochs` and `batch_size` as needed).
   - After training, it will save the model to the specified path (`models/gesture_recognition_model.h5`).
   - A confusion matrix will be displayed to visualize how well the model performed on each gesture class (A-Z).

 7. Check Output
   Once training is completed, the script will print the training and validation accuracy:

Instruction To run the code real_time_prediction.py

Here are the steps to run the real-time gesture recognition code:

 1. Install Required Libraries
Ensure you have the necessary Python libraries installed. Run the following command in the terminal:

terminal
pip install opencv-python cvzone numpy tensorflow


 2. Set Up the Model and Dataset
Make sure that:
- The trained model (`gesture_recognition_model.h5`) is saved in the specified directory (`models/gesture_recognition_model.h5`).
- If the path is different, update the `model = load_model("models/gesture_recognition_model.h5")` line in the script with the correct path to your model.

 3. Save the Script
Save the provided real-time gesture recognition code as a Python file, e.g., `real_time_gesture_recognition.py`.

 4. Run the Script
Open a terminal or command prompt in the directory where the Python file is saved and run the following command to start the webcam-based hand gesture detection:

terminal
python real_time_gesture_recognition.py


 5. Use the Webcam for Predictions
- The script will activate the webcam and display a real-time video feed.
- Place your hand in front of the camera, and the model will attempt to detect and classify the gesture you are showing (A-Z).
- The predicted gesture will be displayed on the video feed in real-time.
  
 6. Exit the Program
To exit the program, press the 'q' key on your keyboard.

 7. Important Notes
- Hand Position: Ensure your hand is visible and centered in the webcam for proper detection.
- Lighting: Use good lighting to improve hand detection and gesture classification accuracy.
